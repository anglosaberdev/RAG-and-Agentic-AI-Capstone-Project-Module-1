Successfully completed **Module 1** of the IBM Generative AI learning program.

This module focused on building an end-to-end Generative AI application that transforms unstructured restaurant descriptions and user reviews into structured JSON data using Large Language Models (LLMs) and Multimodal AI.

## 🎯 Learning Objectives & Achievements

Throughout this module, I developed practical experience in:

1. **LLM-Based Structured Data Extraction**

   - Designed prompts to extract predefined attributes from unstructured restaurant descriptions.
   - Converted natural language into structured JSON records.
   - Validated LLM-generated JSON outputs to ensure data consistency and reliability.

2. **Multimodal AI & Image Captioning**

   - Applied multimodal LLMs to analyze restaurant review images.
   - Generated descriptive captions from visual content.
   - Integrated image captions into structured user review data.

3. **End-to-End Data Processing Pipeline**

   - Built a pipeline to transform unstructured restaurant text into a structured JSON knowledge base.
   - Combined text processing, LLM inference, JSON generation, and data validation.

4. **Python Command-Line Application**

   - Developed a command-line interface (CLI) to manage restaurant records.
   - Implemented CRUD operations:
     - Create new restaurant records.
     - Read and browse existing records.
     - Update restaurant information.
     - Delete restaurant records.

5. **LLM Integration & Data Management**

   - Integrated LLM-powered functions to process new restaurant descriptions.
   - Implemented JSON file handling and persistent data storage.
   - Added backup mechanisms before saving modifications to protect the original data.
